# Klipp

A minimal screenshot and annotation app for macOS 15 or later. Hotkey, select area, annotate, Cmd+Return, paste into Slack or Mail. Lives in the menu bar.

```
brew install --cask jannejava/tap/klipp
```

Or download `Klipp-<version>.dmg` from [Releases](https://github.com/jannejava/homebrew-tap/releases), open it and drag Klipp to Applications. The app is signed with a Developer ID and notarized.

First capture: macOS asks for Screen Recording permission. Allow Klipp under System Settings > Privacy & Security > Screen & System Audio Recording.

## Default hotkeys

| Action | Keys |
|---|---|
| Capture area | Option+Shift+1 |
| Capture fullscreen | Option+Shift+3 |
| Record area | Option+Shift+4 |

Change them in Settings from the menu bar menu.
